## 这是什么

AI API 中转站是把 Claude、GPT、Gemini 等模型的 API 转售给国内开发者的第三方平台：不需要国际信用卡、不用自己解决网络，按人民币计费。它解决的是**支付与接入**问题，不改变模型本身。

代价是：你拿到的是"别人转手的东西"，模型真假、计费口径、资金安全都要自己核。

## 5 个红灯：看到就别充大额

| 红灯 | 为什么危险 | 怎么核 |
|---|---|---|
| 报价低于官方价 1.5 折 | 正常渠道成本压不到这个价，大概率是降级模型或亏本拉新 | 用官方价 × 倍率反推，低于 0.15x 先怀疑 |
| 每日赠送巨额 token | 赠送是获客成本，兑现方式常是限流或降级 | 看赠送规则是否写清有效期与适用模型 |
| 只收 USDT / 只走个人收款码 | 出问题没有支付凭证可追溯 | 优先支持对公、可开票的站 |
| 运营不足 3 个月 | 跑路窗口期最集中 | 看域名注册时间、公告历史、社群活跃度 |
| 页面是模板站、无主体信息 | 换壳成本极低 | 找备案/主体/联系方式，找不到就降级 |

## 4 个绿灯：可以先小额试

1. **公开价目与倍率**：每个模型、每个渠道分组都写清倍率，而不是一句"低至 X 折"
2. **可开票、退款条款明确**：对公转账、发票类型、退款手续费写清楚
3. **有可核验的检测记录**：能给出检测时间、样本量、判定口径，而不是"我们保证真"
4. **公告持续更新**：最近 30 天有版本/价格/线路变更记录，说明有人在维护

## 价格怎么比：倍率与应扣

- **倍率** = 本站单价 ÷ 官方价。0.5x = 半价，1.0x = 与官方同价。
- **应扣** = 官方价 × 渠道倍率 × 实际用量；缓存读写按同一倍率折算。
- **对账口径**：完全对得上 = 分毫不差；对得上 = 误差 ≤5%；比标价还便宜 = 站方明示让利。

三个常见坑：

1. 只比输入价，不看输出价与缓存价——很多站输入价很低，输出价按 4–5 倍收
2. 缓存读写不跟倍率走，重度使用下账单能差出几倍
3. 美元与人民币不是严格 1:1，且未计折扣与手续费

## 下单前 10 项核对表

- [ ] 目标模型是否在售，倍率是否写清
- [ ] 起充金额与退款条件
- [ ] 是否支持发票、对公、合同
- [ ] Key 的权限范围、日志保留策略
- [ ] 是否限制并发、RPM/TPM
- [ ] 缓存计费是否单独定价
- [ ] 是否有客服响应时限
- [ ] 公告最近一次更新时间
- [ ] 先小额充值跑一轮对账（应扣 vs 实扣）
- [ ] 准备至少一家替代站，避免单点

## 客户端接入的通用步骤

不管用 Claude Code、Cursor、Cherry Studio 还是 Dify，套路一样：

1. 拿到 `base_url`（有的站叫 API 地址/接口地址）与一枚专用 Key
2. 在客户端里把 Base URL 指向该站，模型名按该站文档填写（大小写与连字符要对）
3. 先发一条最小请求，确认返回结构与官方一致（字段、stop_reason、usage）
4. 跑一轮对账：记录应扣与实际扣费，误差 >5% 就追问渠道
5. 确认无误后再把生产流量切过去

## 风险提示

中转站是第三方服务，存在掉包、降级、限流、跑路等风险。控制单次充值金额、保留支付凭证、准备替代方案，是使用这类服务的基本操作。本清单只做公开信息整理，不构成推荐或背书。
